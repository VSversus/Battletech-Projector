# Ideas


## Current Idea

- Name: Dice Roller
- What it does: A simple CLI tool that simulates a 2d6 roll for Classic BattleTech. Optionally accepts a target number and displays the probability of success and whether the roll succeeds or fails.
- First small step: Simulate 2d6 dice roll and returns a result.

## Next Idea

- Name: Hit Location Simulator
- What it does: A CLI tool that simulates hit location rolls for Classic BattleTech. Displays the resulting hit location and optionally runs multiple simulations to analyze the distribution of hits across different locations.
- First small step: Simulate one 2d6 roll. Map the result to the correct hit location. Support front attacks only; other directions can be added later. Include basic unit tests for the hit location mapping.

## Features Ideas

- To-Hit Calculator (A CLI tool that calculates the required 2d6 roll and probability of hitting a target in Classic BattleTech, taking into account relevant modifiers such as attacker movement, target movement, range, and terrain.)
